# 🍔 Food & Confectionaries Delivery Web Application

A full-stack Food Delivery & Confectionaries Web Application developed using PHP, MySQL, Bootstrap, JavaScript, and XAMPP.

This application allows users to browse food items, place orders, apply coupons, track deliveries, and manage orders through dedicated Admin and Delivery dashboards.

---

# 📌 Features

## 👤 User Features
- User Signup & Login
- Browse Food Products
- Product Search & Category Filters
- Product Details Page
- Add To Cart System
- Quantity Management
- Coupon Application
- Checkout & Payment Flow
- Order Tracking System
- Live Delivery Status Updates

---

## 🛒 Product Features
- Product Listings
- Combo Recommendations
- Food Categories
- Ratings & Reviews
- Serving Size Information
- Ingredients Information
- Allergen Information

---

## 👨‍💼 Admin Features
- Admin Dashboard
- Product Management
- Inventory Management
- Add/Edit/Delete Products
- Order Monitoring
- Sales Analytics
- Shipment Status Updates

---

## 🚚 Delivery Features
- Delivery Dashboard
- Accept Delivery Orders
- Update Delivery Status
- Real-Time Order Tracking Base
- Delivery Completion Workflow
